# 学习计划与课程管理系统

一个用于管理课程、记录学习时长、查看学习进度和设置提醒的课程作业项目。页面采用蓝白配色，前端使用 HTML、CSS 和 JavaScript，后端使用 Node.js 与 SQLite。

## 打开系统

Windows 用户双击根目录的 **启动系统.bat**。启动窗口会保留并显示结果，启动成功后会自动打开 <http://127.0.0.1:3000>。确认启动成功后，可以按任意键关闭启动窗口，服务会继续在后台运行。使用完成后，双击 **停止系统.bat** 停止服务。

如果浏览器没有自动打开，请在浏览器地址栏手动输入 `http://127.0.0.1:3000`。如果页面仍无法访问，请重新双击 **启动系统.bat**，查看保留窗口中的错误信息；端口被占用时，可先运行 **停止系统.bat**，再重新启动。项目自带 `runtime/node.exe`，无需安装 Node.js 或运行 npm install。

演示账号：`student`，密码：`Student123`。也可以在登录页面注册自己的账号，各账号的课程、学习记录和提醒分别保存。

演示账号初始包含 12 门课程、60 条学习记录和 10 条学习提醒。新注册账号从空白开始。演示数据可以编辑或删除，删除后不会在重启时自动恢复。

系统以登录注册页作为入口。登录或注册成功后默认进入“课程管理”，登录后的四个业务页面为“课程管理”“学习记录与进度统计”“学习计划管理”和“学习提醒”。

## 主要功能

- **课程管理**：新增、编辑、删除课程，填写分类、教师、目标学习时长、截止日期和课程说明。
- **登录注册**：注册账号、登录、查看当前用户并安全退出。
- **学习记录与进度统计**：在该页面按课程记录学习日期、学习分钟数和学习内容，并查看累计时长、课程进度以及最近七天的学习统计。
- **明细查看**：学习记录明细默认展示，每页显示 10 条，支持课程和日期筛选。日期使用中文日历，支持选择年月、今天和清空筛选。
- **学习计划管理**：按“每周计划 / 中期计划 / 长期计划”三个层级分页管理学习计划，支持关联课程分类、填写目标并由 DeepSeek 大模型生成规划。计划以竖向时间线卡片呈现，可展开查看 AI 规划与打卡任务表格（事件 / 科目 / 目标 / 打卡任务 / 图片凭证），支持上传图片作为完成凭证。
- **AI 学习规划助手**：页面右下角提供可拖动的 🤖 悬浮按钮，点击后可展开多轮对话，咨询课程拆解、算法复习、知识依赖、项目学习路线和计划调整建议。按钮带有雷达扩散动画，支持清空对话和收起面板。
- **学习提醒**：设置单次、每日或每周提醒，可关联课程、暂停提醒或标记完成。重复提醒完成后会推进至下一个提醒时间。

提醒需要系统页面保持打开。到期后页面显示提醒；授权浏览器通知后，还可以显示系统通知。可在提示栏点击“全部已读”，或在提醒列表逐条点击“已读”。单次提醒显示为“已读”，重复提醒安排下一次时间；刷新页面、重新登录或重启服务后不会重复显示已读提示。已读操作不会增加学习时长。关闭页面期间不会发送通知，再次打开页面会展示尚未处理的到期提醒。

课程进度按累计学习分钟数与目标分钟数计算，最高显示 100%。删除课程时会同时删除该课程的学习记录和关联提醒，请先确认不再需要这些数据。

## 开发运行

本项目需要 Node.js 24，使用其内置的 `node:sqlite`，不依赖第三方包。

```powershell
node server.js
```

也可以运行：

```powershell
npm start
npm test
```

未安装 Node.js 时，使用项目附带的运行时：

```powershell
.\runtime\node.exe server.js
.\runtime\node.exe --test tests\api.test.js tests\demo-data.test.js
```

默认端口为 `3000`。可通过环境变量 `PORT` 更改端口，通过 `DATA_DIR` 指定数据库保存目录。

### AI 配置

AI 模型配置保存在 `data/ai-config.json`，当前默认使用 DeepSeek。每次生成计划或发送助手消息时，服务都会重新读取该文件，因此修改 `apiUrl`、`model` 或 `apiKey` 后刷新网页即可生效，无需重启服务。

```json
{
  "provider": "DeepSeek",
  "apiUrl": "https://api.deepseek.com/chat/completions",
  "model": "deepseek-flash",
  "apiKey": "你的 API Key"
}
```

不要将包含真实 API Key 的 `data/ai-config.json` 上传到公开代码仓库。

## 接口概览

接口以 `/api` 开头，成功响应为 `{ "data": ... }`，错误响应为 `{ "error": "错误信息" }`。登录后通过 Cookie 保持会话。

| 接口 | 方法 | 用途 |
| --- | --- | --- |
| `/auth/register` | POST | 注册账号 |
| `/auth/login`、`/auth/logout` | POST | 登录、退出 |
| `/auth/me` | GET | 当前登录用户 |
| `/courses` | GET、POST | 查看、新增课程 |
| `/courses/:id` | PUT、DELETE | 编辑、删除课程 |
| `/records` | GET、POST | 查看、新增学习记录 |
| `/records/:id` | PUT、DELETE | 编辑、删除学习记录 |
| `/stats` | GET | 学习进度与时长统计 |
| `/reminders` | GET、POST | 查看、新增提醒 |
| `/reminders/:id` | PUT、DELETE | 编辑、删除提醒 |
| `/reminders/:id/complete` | POST | 完成提醒 |
| `/reminders/read` | POST | 标记单条或批量到期提醒已读 |
| `/plans` | GET、POST | 查看（含任务计数）、新增学习计划 |
| `/plans/:id` | GET、PUT、DELETE | 查看计划详情（含任务）、编辑、删除计划 |
| `/plans/:id/tasks` | GET、POST | 查看、新增计划的打卡任务 |
| `/plans/:id/tasks/:taskId` | PUT、DELETE | 编辑、删除打卡任务 |
| `/plans/ai` | POST | 调用 DeepSeek 大模型生成计划规划 |
| `/ai/chat` | POST | 与 AI 学习规划助手进行多轮对话 |
| `/uploads` | POST | 上传打卡图片凭证 |
| `/uploads/:userId/:filename` | GET | 读取打卡图片凭证 |
| `/health` | GET | 服务健康检查 |

## 数据备份与迁移

账号和业务数据保存在 `data` 文件夹。备份前先双击 **停止系统.bat**，然后复制整个 `data` 文件夹；移动到另一台 Windows x64 电脑时，可复制整个项目文件夹后重新启动。不要只复制网页文件，也不要在服务运行期间单独移动数据库文件。

接口测试使用端口 `3101` 和临时数据库；演示数据升级测试也使用独立临时数据库，不会修改正常运行的学习数据。

## 视障友好适配

现有页面已补充键盘焦点、跳转主内容、表单与表格语义、AI 对话状态、日期选择键盘操作，并支持系统高对比度和减少动画偏好。助手收起时可按 Alt+方向键移动，Escape 可收起对话。刷新网页即可加载前端改动。
